## Product bugs found

Status 2026-10-11: items 1 to 3 are fixed in `main` (see each item). The captures were made before the fixes; the stand fixups for items 1 to 3 are no longer needed on a stand that runs the current code.
1. **Fixed** (F-05, PR #1166, commit `49bbbf5f1`). Receipts list returned 503 once a receipt is closed or cancelled (jsonb `close_summary` / `cancel_summary`). Steps: close any receipt (RF Close Receipt), open Inbound > Receipts. Stand fixup: set both columns to NULL (`stand-up.sh fixups`).
2. **Fixed** (F-05, PR #1166, commit `49bbbf5f1`). Audit Log list returned 503 when `audit_log.detail` is a JSON object. Steps: change a user, open Users & Roles > Audit Log. Same fixup.
3. **Fixed** (F-04, PR #1165, commit `4f4ef04ab`; wms-enterprise 018 also scrubs old rows). The audit log stored password hashes and salts in `detail` of user changes. Steps: create/edit a user, read the row. The fixup masks them before the screenshot.
4. Carrier delivery (Pick by Area, PKA30 at PACK01) with an order whose picks are "Bypassed" (non-cartonizable) fails at hand-off. Steps: release an order for a non-cartonizable SKU, pick it by area with a carrier, deliver. Seeded order HP-20871 is left as a draft for that reason.
5. Enterprise > Configuration > Warehouses opens an empty content area (no list). Steps: Enterprise mode, sidebar Warehouses.
6. Breadcrumb of a record opened from a list shows the record id, and Order lines toolbar shows an enabled Save without edits (shipment-order-detail).
7. Unverified: Pick Result screen (PICK12) shows `Picked 0` after a full pick of 60.
