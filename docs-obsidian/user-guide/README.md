## Using the guide

- Start with the guide for your role, then follow its related-page links.
- Menu paths use `Sidebar > Group > Item`.
- Text in **bold** matches a button, field or terminal label.
- Text in `code format` is a value to type, scan or select.
- Screenshots are captured from the current product and reviewed in English before publication.
