# Localization

Use Studio's localization view to maintain translated labels. Start from the module and labels used by the screen you are changing.

## Update a label

1. Select the module in Graph Explorer, then choose **i18n**.
2. Find the label or translation entry.
3. Check the language and existing value before editing.
4. Save the change using the available editor controls.
5. Reopen the affected form in that language and check the result.

A label key identifies the text. A translated value changes what the user reads; it should not change the underlying field or action code.

## Check the whole screen

Use realistic text lengths. Check tab captions, toolbar actions, field labels and validation messages, not just the page title. A short English label can become longer in another language.

Languages available to the WMS and languages published on this documentation website are separate settings. This documentation is currently written in English.
