# Entity Wizard

The Entity Wizard creates a starting set of metadata for an entity and its forms. It saves repetitive setup; review the generated result before treating it as a finished workflow.

## Templates

The current wizard offers these templates:

- List Only
- List → Detail
- Header / Detail
- Tabbed Form
- Tabbed Header / Detail
- Tabbed Master / Detail
- List → Detail + Child

## Prepare the input

Choose the intended data source and table. Check the primary key and the columns you want to expose. For a parent-child template, identify both entities and the relationship between them.

Use names that make the generated forms and actions easy to recognise. Field types, display names and layout still need review for the intended users.

## Generate and review

1. Work in a draft module.
2. Choose the template that matches the screen structure you need.
3. Select the data source, tables and columns presented by the wizard.
4. Review the summary before creating the records.
5. Find the generated BIOs, forms, toolbars and navigation in the graph.
6. Check the designer layout and every generated action.
7. Apply and test the list, detail and return journey in the intended environment.

The wizard is not a substitute for reviewing access, validation and operational behaviour. Changes to database structure need their own review and recovery plan.
